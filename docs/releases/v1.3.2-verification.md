# 1.3.2 发布验证说明

应用、安装包、免安装包及升级包统一使用版本 `1.3.2`。

## 功能验证

- Release 自动测试：159 项通过。
- 正式 WPF 控件渲染：11 项通过，覆盖成本、余额、窗口额度及紧凑布局。
- 本次会话使用已配置的真实账户验证 OpenCode Go、Fireworks AI、DeepSeek 和 Command Code，四个提供商查询均成功。Fireworks 控制台余额已与 API Key 的账户归属核对，重启后会话恢复成功。
- 真实查询图像和账户数值仅保存在本机诊断目录，不包含在源码或发布资产中。

真实验证仅覆盖上述账户和当时的服务状态。控制台接口与页面结构可能随供应商更新而变化。

## 打包与安装验证

使用 `packaging/release.ps1 -Version 1.3.2` 从同一份 Windows x64 自包含发布目录生成三个包，并检查程序版本及正式产品标识。

使用 `packaging/verify-packages.ps1` 完成 22 项隔离安装检查，包括首次安装、同版本修复、卸载、从模拟 1.2.2、1.2.3、1.3.0 和 1.3.1 基线升级，以及无安装记录、文件锁定、运行中和降级等拒绝场景。正式产品注册项保持不变。

验证范围为 CurrentUser；管理员提升及 HKLM 安装路径未实测。旧版本基线为版本化程序文件及安装登记，不等同于真实账户状态迁移。隔离安装验证不启动安装后的应用。

发布包包含 .NET 8，不包含 WebView2 Runtime 或 Codex CLI。`SHA256SUMS.txt` 提供发布资产的校验值。
