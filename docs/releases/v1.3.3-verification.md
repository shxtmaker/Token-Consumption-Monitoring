# 1.3.3 发布验证说明

应用、安装包、免安装包及升级包统一使用版本 `1.3.3`。

## 功能验证

- Release 自动测试：200 项通过，其中包含 41 项 OpenDesign 用例。
- OpenDesign 使用真实桌面 WebView2 会话，成功取得工作空间 USD 钱包余额、5 小时及 7 天套餐窗口；已核对生产面板和桌面组件的显示。
- 关闭首次登录进程后，新进程无需再次登录即可恢复会话，两个查询来源均取得未过期数据。
- 配置保存与重载、跨工作空间隔离、DeepSeek 查询来源隔离、通用探测隔离及错误状态由自动测试覆盖。
- 本版本未重新验证其他供应商的真实账户。详细范围见 [OpenDesign 接入验证](../opendesign-verification.md)。

真实账户数据、登录配置、截图及本机诊断报告不包含在源码或发布资产中。控制台查询依赖供应商私有接口，接口变化可能需要更新应用。

## 打包与安装验证

使用 `packaging/release.ps1 -Version 1.3.3` 生成 Windows x64 自包含安装包、免安装包及升级包，核对应用文件版本与正式产品标识。

`packaging/verify-packages.ps1` 的 25 项隔离安装检查通过：首次安装、同版本修复、卸载、从模拟 1.2.2、1.2.3、1.3.0、1.3.1、1.3.2 基线升级，以及无安装记录、文件锁定、运行中和降级等拒绝场景。正式产品安装登记保持不变。

安装验证范围为 CurrentUser；管理员提升及 HKLM 安装路径未实测。旧版本基线为版本化程序文件及安装登记，不等同于真实账户状态迁移。安装验证不启动安装后的应用；真实功能验证来自装配生产查询、会话、运行时协调器及 UI 的独立桌面验收程序。

发布包包含 .NET 8，不包含 WebView2 Runtime 或 Codex CLI。源码归档由发布提交生成，包含应用、测试、文档和打包脚本；`SHA256SUMS.txt` 提供安装包、免安装包、升级包和源码归档的校验值。
