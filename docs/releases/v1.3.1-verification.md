# 1.3.1 发布验证说明

应用及三个 Windows x64 发布包统一使用版本 `1.3.1`。本版本调整小组件布局和展示状态，并重新整理使用文档。

## 应用与界面

Release 自动测试覆盖配置恢复、凭据提交、查询契约、来源选择及运行时生命周期。

`tests/OfficialQuerySmoke` 使用正式 WPF 控件与合成数据，输出九张 PNG，覆盖凭据表单、候选列表、小组件、长标题、不同长度的倒计时、多币种余额及额度说明。浮窗验收宽度直接读取正式窗口配置，避免测试与产品尺寸不一致。

合成截图不代表真实账户数据。本版本未重新逐一使用供应商真实密钥联调接口；既有接口验证记录见[查询覆盖验证](../query-coverage-verification.md)。

## 发布包与升级

`packaging/release.ps1` 从同一份自包含发布目录生成安装包、免安装包和升级包，并校验版本、产品 AppId 和互斥量。

```powershell
pwsh ./packaging/release.ps1 -Version 1.3.1
pwsh ./packaging/verify-packages.ps1 -PublishDirectory <本次打包输出的publish目录>
```

隔离验证使用独立 AppId、安装目录和注册项，覆盖以下场景：

- 首次安装、同版本修复和卸载。
- 从模拟 1.2.2、1.2.3、1.3.0 安装记录及对应版本化 PE 基线升级到 1.3.1。
- 检查升级后的原路径、注册版本、程序文件哈希及自定义配置哨兵。
- 拒绝无安装记录、变更目录、程序运行、文件锁定或降级时的升级请求。
- 拒绝程序运行或文件锁定时的卸载请求。
- 检查正式产品的每用户安装注册项未变，测试注册项已注销。

验证程序将结果写入 `artifacts/packaging-verification/<验证标识>/verification.json`。打包清单位于对应的 `artifacts/packaging/<版本与标识>/release-manifest.json`，记录文件大小和 SHA-256。

## 验证范围

安装验证使用 CurrentUser 范围。所有用户安装的管理员提升及 HKLM 路径不在本次自动化实测范围内。旧版本基线验证安装登记与程序文件替换，不等同于真实账户状态迁移测试。

隔离验证不会运行安装后的应用，也不会读取真实用户配置或凭据。发布包包含 .NET 8 运行组件，不包含 WebView2 Runtime 或 Codex CLI。
