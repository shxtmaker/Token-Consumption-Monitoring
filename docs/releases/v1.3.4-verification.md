# 1.3.4 发布验证说明

应用、安装包、免安装包及升级包统一使用版本 `1.3.4`。

## 修正范围

1.3.3 的 OpenDesign 查询要求把控制台链接填入 Base URL，保留推理端点的已有页面只能探测连接。1.3.4 将工作空间保存到独立字段，在原 API 页面上通过显式启用的私有兼容方法读取余额与额度。

原 Base URL、API Key 引用、协议和模型列表不被改写。API Key 不会传送到控制台接口。1.3.3 已建立的控制台页面继续兼容。

## 已执行功能验证

- 自动测试：215 项通过。包括 54 项 OpenDesign 用例，以及 API 页面控制台登录分发和会话失效回归。
- 编辑器与持久化：工作空间 ID 和控制台链接输入、配置保存重载、已有 API 配置与密钥引用保留、非法工作空间拒绝、工作空间切换后的缓存及浏览器配置隔离。
- 默认注册表与运行时：API 页面私有会话返回余额和两个套餐窗口；部分失败与鉴权失败保持独立，缺失数据不生成零值。
- 正式 WPF 控件：13 张渲染图与交互检查通过。新增 OpenDesign 私有兼容表单的宽窗口及 620px 窄窗口，验证保存、重新编辑、API Key 保留和登录事件分发。

以上自动化使用合成响应。1.3.3 已完成的真实控制台读取与重启恢复继续作为接口契约依据；本次未将它们计为 1.3.4 API 页面模式的真实账户验收。正式安装后的应用启动、该模式的真实读取以及其他供应商账户未在本次自动化中重新验证。

## 发布包验证流程

`packaging/release.ps1 -Version 1.3.4` 从同一 Windows x64 自包含目录生成安装包、免安装包和升级包。程序文件版本与提交身份在打包后核对。

`packaging/verify-packages.ps1` 包含 28 项隔离检查：首次安装、修复、卸载、从模拟 1.2.2、1.2.3、1.3.0、1.3.1、1.3.2、1.3.3 基线升级，以及无安装记录、文件锁定、运行中和降级拒绝等场景。检查限定 CurrentUser，采用独立安装标识；管理员安装与真实用户配置迁移不在该检查范围内。

发布资产为安装包、免安装包、升级包、源码归档和 `SHA256SUMS.txt`。各平台上传完成后分别下载资产并核对 SHA-256；测试截图、真实账户配置和浏览器登录状态不进入发布资产。
