# 1.3.0 发布验证

日期：2026-09-08。应用、安装包、免安装包和升级包统一使用版本 `1.3.0`。

## 应用验证

- Release 自动测试 136 项通过，0 失败、0 跳过。
- 正式 WPF 控件完成凭据表单、候选列表、小组件等七张合成数据截图验证。
- 本机 Codex CLI 0.153.4 的账户窗口查询成功，返回三个能力条目；账户累计 Token 查询成功，返回一个能力条目。
- Codex 扫描核验对应接口；未登录、不支持、权限、网络和结构错误不形成可用候选。首次扫描与重新扫描的界面列表仅保留可用方法。

## 打包与升级验证

`packaging/release.ps1` 从同一份 Windows x64 自包含发布目录生成三个包，并校验项目版本、程序文件版本、安装 AppId 和应用互斥量。

使用 `packaging/verify-packages.ps1` 在独立 AppId 和独立目录中执行每用户安装验证，16 项通过：

- 安装真实 1.3.0 程序文件、同版本修复及卸载。
- 模拟 1.2.2／1.2.3 安装记录和对应版本化 PE 基线，分别验证升级到 1.3.0 后的原路径、注册版本和程序文件哈希。
- 拒绝没有匹配安装记录、指定其他目录、程序运行、文件锁定以及降级的升级请求。
- 拒绝程序运行或文件锁定时的卸载请求。
- 安装目录中的自定义配置哨兵在升级和卸载后仍保留。
- 正式产品的每用户安装注册项前后保持一致，测试安装注册项完成注销。

隔离验证没有运行安装后的应用，也没有读取或更改真实用户配置和凭据。旧版本基线用于验证安装登记和文件替换，不能替代旧版本真实账户状态的迁移测试。

## 验证边界

每用户安装已实测；所有用户安装的管理员提升及 HKLM 路径未在本次自动化中实测。安装脚本使用 Inno Setup 的既有安装范围识别，升级时复用对应范围的原安装目录。

发布包包含 .NET 8 运行组件，不捆绑 Microsoft Edge WebView2 Runtime 或 Codex CLI。其他新增提供商接口采用契约和模拟响应验证，尚未逐一使用真实密钥联调；详细边界见[查询验证记录](../query-coverage-verification.md)。
