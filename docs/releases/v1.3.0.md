# TokenConsumptionMonitoring 1.3.0

本版本扩展用量与额度查询，并简化扫描后的候选方法列表。

## 更新内容

- 新增 OpenRouter Key 额度、今日费用及账户 credits 查询。
- 新增 OpenAI、Anthropic 组织用量及费用查询，支持对应 Admin Key。
- 新增 Moonshot 余额、Z.ai／智谱和 MiniMax Coding Plan 窗口查询。
- 新增通过本机已登录 Codex CLI 查询订阅窗口和账户累计 Token。
- DeepSeek 余额保留全部币种；不同币种、来源和窗口分别展示。
- 首次扫描和重新扫描后，候选方法链仅显示可用方法。重扫结果替换旧列表，没有可用方法时显示“0 个可用”。
- 凭据类型明确区分普通 API Key、Admin Key、Management Key 和本机 Codex 登录。

## 下载选择

| 文件 | 适用场景 |
|---|---|
| `TokenConsumptionMonitoring-Setup-1.3.0.exe` | 首次安装或同产品覆盖安装。 |
| `TokenConsumptionMonitoring-Portable-1.3.0.zip` | 免安装运行，或退出程序后替换原免安装版文件。 |
| `TokenConsumptionMonitoring-Upgrade-1.3.0.exe` | 更新已安装的同产品，沿用原安装目录。 |

三个包均适用于 Windows x64，并包含 .NET 8 运行组件。升级前请从托盘退出程序。升级包需要同产品安装记录，不能用于免安装版，也不能将旧产品 `TokenUsageMonitorV3` 迁移为本产品。

同一 Windows 用户下，页面配置保存在 `%APPDATA%\TokenConsumptionMonitoring`，密钥保存在 Windows 凭据存储。安装、升级和卸载不删除这些数据。免安装包不包含用户数据，跨机器复制程序不会带走已保存的密钥。

完整项目源码可从本 Release 的源码归档下载，包含应用、测试、文档和打包脚本。

## 查询条件

DeepSeek 控制台登录需要另行安装 Microsoft Edge WebView2 Runtime；三个包均不捆绑该运行时。Codex 查询需要同一用户下已登录且支持账户读取方法的 Codex CLI。组织账务接口需要管理权限，普通推理密钥不能代替管理密钥。

组织报表采用最近已完成的 UTC 日，Codex 账户累计 Token 不标为今日用量。服务方缺失、未支持或无法确认的数据保持未知，不推算为零。

提供商接口已通过契约与模拟响应验证，Codex 账户查询已完成本机联调；其余新增接口尚未逐一使用真实账户密钥联调。详细配置和范围见[查询覆盖说明](../query-coverage.md)。
